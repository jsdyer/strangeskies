READING THE RECORDS

What gets reported?

CADORS logs preliminary aviation occurrences. The combined weather balloon, meteor, rocket and CIRVIS/UFO event label covers several kinds of reports. It does not establish what was seen.

Where are the narratives?

The downloadable tables contain locations, categories, events and aircraft details. Use the CADORS number in Transport Canada's query for the narrative where one is available.
